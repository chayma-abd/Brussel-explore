# BrusselsExplorer - Stripmuren in Brussel

**Studenten:** Chayma en Sabrine

## Project
Webapplicatie die stripmuren in Brussel toont met kaart, tabel, zoeken, filteren, sorteren en favorieten.

## API
- OpenData Brussels - Parcours BD (Stripmuren)
- 20 locaties opgehaald

## AI gebruik
AI (ChatGPT) gebruikt voor:
- Hulp bij API integratie
- Debuggen van CORS problemen
- Opzetten basisstructuur

Zelf gedaan:
- Eigen styling aangepast
- Dataset gekozen (Parcours BD)
- Favorieten functionaliteit
- Filter en sorteer logica

## Bronnen
- OpenData Brussels API
- Leaflet.js voor kaart
- Lessen Dynamic Web van leerkracht

## Installatie
1. Download alle bestanden in een map
2. Open index.html met Live Server
3. Klik op "Laad locaties"
